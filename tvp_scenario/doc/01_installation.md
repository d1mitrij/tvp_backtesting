# Installation

Three independent simulation frameworks are provided under `s4_scenarios/`:

| Framework | Directory | Solver | Prerequisites |
|-----------|-----------|--------|---------------|
| **OSeMOSYS** (tz-osemosys) | `osemosys/` | HiGHS (pip) | Python only |
| **GCAM** (pygcam) | `gcam/` | GCAM C++ (compiled) | Build toolchain + Java + R + Python |
| **MESSAGEix** (message-ix) | `messageix/` | GAMS (demo license) | GAMS + Java + Python |

All frameworks share the same project finance CSVs in `modeled_input_data/`
and produce identical IAMC-format outputs and tvp_dbio intensity factors for
cross-model comparison.

---

## Common prerequisites

| Requirement | Minimum version | Notes |
|-------------|----------------|-------|
| Python | 3.11 | Tested on 3.11.x (WSL2 / Linux) |
| pip | 23+ | Bundled with Python |
| Conda environment | optional | Recommended for isolation |

```bash
conda create -n env_s4 python=3.11 -y
conda activate env_s4
```

## OSeMOSYS (tz-osemosys) — pip only

```bash
cd osemosys
pip install -r requirements.txt
```

`requirements.txt` installs:

```
tz-osemosys>=0.3.7     # OSeMOSYS framework (linopy backend)
highspy>=1.13.0        # HiGHS LP solver (open-source, pip-installable)
pyam-iamc>=2.0.0       # IAMC scenario analysis
pandas>=2.0
numpy>=1.24
xarray>=2023.1
```

### Verify OSeMOSYS installation

```bash
python3 -c "
from tz.osemosys import Model
from linopy import available_solvers
import pyam
print('tz-osemosys: OK')
print('Solvers available:', available_solvers)
print('pyam:', pyam.__version__)
"
```

Expected output:
```
tz-osemosys: OK
Solvers available: ['highs']
pyam: 2.x.x
```

If `available_solvers` is empty: `pip install highspy`

### OSeMOSYS troubleshooting

| Symptom | Fix |
|---------|-----|
| `ModuleNotFoundError: No module named 'tz'` | Activate correct env; namespace package installs under `tz/osemosys/` |
| `ModuleNotFoundError: No module named 'tz_osemosys'` | Use `from tz.osemosys import Model`, not `import tz_osemosys` |
| `available_solvers: []` | `pip install highspy` |
| `AttributeError: 'RunSpec' object has no attribute 'solve'` | Use `Model.from_yaml(...)`, not `load_model(...)` — the latter returns `RunSpec` which has no solver |

## GCAM (pygcam) — build from source + pip

On Linux, GCAM has no pre-built release package; it must be compiled from
source. Pre-built packages are available for Mac and Windows from the
[GCAM releases page](https://github.com/JGCRI/gcam-core/releases).

### Step 1: Install build dependencies (conda)

```bash
conda install -c conda-forge cmake boost-cpp libxml2 eigen tbb-devel openjdk git-lfs
```

Key paths after installation (substitute your conda prefix):

| Variable | Value |
|----------|-------|
| `BOOST_INCLUDE` | `$CONDA_PREFIX/include` |
| `EIGEN_INCLUDE` | `$CONDA_PREFIX/include/eigen3` |
| `JAVA_INCLUDE` | `$CONDA_PREFIX/lib/jvm/include` |
| `JAVA_LIB` | `$CONDA_PREFIX/lib/jvm/lib/server` |
| `TBB_INCLUDE` | `$CONDA_PREFIX/include` |
| `TBB_LIB` | `$CONDA_PREFIX/lib` |

### Step 2: Clone and compile GCAM

```bash
git clone --depth=1 --branch gcam-v7.3 \
    https://github.com/JGCRI/gcam-core.git ~/gcam-v7.3

# Initialise the hector climate submodule
cd ~/gcam-v7.3
git submodule update --init cvs/objects/climate/source/hector

# Build (uses GCAM's Linux Makefile)
export BOOST_INCLUDE=$CONDA_PREFIX/include
export BOOST_LIB=$CONDA_PREFIX/lib
export EIGEN_INCLUDE=$CONDA_PREFIX/include/eigen3
export JAVA_INCLUDE=$CONDA_PREFIX/lib/jvm/include
export JAVA_LIB=$CONDA_PREFIX/lib/jvm/lib/server
export JARS_LIB=$HOME/gcam-v7.3/exe
export TBB_INCLUDE=$CONDA_PREFIX/include
export TBB_LIB=$CONDA_PREFIX/lib

cd cvs/objects/build/linux && make -j$(nproc) gcam
# Binary written to: ~/gcam-v7.3/exe/gcam.exe  (~287 MB, ~20–40 min)
```

### Step 3: Generate GCAM input XML data (gcamdata)

GCAM reads ~1 000 XML input files generated by the `gcamdata` R package.
This step is required once per GCAM installation; it takes **2–3 hours**.

```bash
# Install R via conda
conda install -c conda-forge r-base r-devtools

# Install gcamdata R dependencies
cd ~/gcam-v7.3/input/gcamdata
Rscript -e "
  options(repos=c(CRAN='https://cloud.r-project.org'))
  install.packages(c('devtools','dplyr','tidyr','data.table','assertr',
                     'drake','tibble','readr','stringr','XML','xml2'),
                   dependencies=TRUE, quiet=TRUE)
"

# Run the gcamdata pipeline (~2–3 h, writes XML to input/gcamdata/xml/)
nohup Rscript -e "devtools::load_all('.'); driver(write_output=FALSE, write_xml=TRUE)" \
    > /tmp/gcamdata_build.log 2>&1 &

# Monitor progress
tail -f /tmp/gcamdata_build.log
ls input/gcamdata/xml | wc -l   # ~1 000 files when complete
```

### Step 4: Install Python packages

```bash
cd /path/to/s4_scenarios/gcam
pip install -r requirements.txt
```

`requirements.txt` installs:

```
pygcam>=1.11.0       # workflow manager: gt run / gt query (latest: 1.11.1)
gcam-reader>=1.1.0   # reads GCAM CSV query outputs into pandas
pandas>=2.0
numpy>=1.24
lxml>=4.9            # XML generation and XPath in iamc_bridge
```

### Step 5: Configure pygcam

`gt init` requires an interactive terminal. Write `~/.pygcam.cfg` directly:

```ini
[DEFAULT]
GCAM.DefaultProject = s4-scenarios
GCAM.RefWorkspace   = /home/<user>/gcam-v7.3
GCAM.ProjectRoot    = /home/<user>/GCAM/projects
GCAM.SandboxRoot    = /home/<user>/GCAM/sandbox
GCAM.LogLevel       = INFO
GCAM.LogConsole     = True

[s4-scenarios]
GCAM.ProjectDir = /path/to/s4_scenarios/gcam
```

Verify:
```bash
gt config GCAM.RefWorkspace   # should print ~/gcam-v7.3
gt run --help
```

### GCAM troubleshooting

| Symptom | Fix |
|---------|-----|
| `gt: command not found` | `pip install pygcam`; ensure pip bin dir is on `$PATH` |
| `No module named 'pkg_resources'` | Patch `pygcam/config.py` and `XMLFile.py` to use `importlib.resources` (Python 3.11 setuptools issue) |
| `GCAM binary not found` | Set `GCAM.RefWorkspace` in `~/.pygcam.cfg` |
| `XML input files missing` | Run gcamdata Step 3 above |
| `BaseX database error` | GCAM requires Java 11+: `java -version` |
| `gcam_reader` import error | `pip install gcam-reader` (hyphenated package name) |
| Sandbox already exists | `gt run --overwrite -s ssp1` |
| `pygcam>=2.4.0` not found | Latest available is 1.11.1; use `pygcam>=1.11.0` |

### Java

GCAM's BaseX output database requires Java 11+. Install via conda (includes
JNI headers needed for compilation):

```bash
conda install -c conda-forge openjdk
java -version   # OpenJDK 21+
```

## MESSAGEix (message-ix) — GAMS + pip

### Step 1: Install GAMS

Download the [GAMS demo license](https://www.gams.com/download/) for Linux.
The demo license covers models up to ~2 000 rows × 2 000 columns (sufficient
for tutorial models; full MESSAGEix-GLOBIOM R11 requires a full license).

```bash
export GAMS_PATH=/path/to/gams   # add to ~/.bashrc
```

### Step 2: Install Python packages

```bash
cd messageix
pip install "message-ix[report,tutorial]>=3.6.0"
pip install "message-ix-models"   # provides mix-models CLI
pip install gamspy                # provides gams.transfer (Python API)
```

### Step 3: Fetch the world model snapshot

```bash
# Downloads ~400 MB MESSAGEix-GLOBIOM R11 baseline from Zenodo
mix-models fetch snapshot-1
```

### Step 4: Run

```bash
python run_simulation.py --dry-run    # validate parameters, no GAMS solve
python run_simulation.py              # all 5 SSPs (requires GAMS + snapshot)
```

### MESSAGEix troubleshooting

| Symptom | Fix |
|---------|-----|
| `No module named 'gams'` | `pip install gamspy` |
| `IXMP4Backend() got unexpected keyword argument 'url'` | Use `ixmp4_name=` + `dsn=` (ixmp 3.11+ API) |
| `NoDefaultRunVersion` | Snapshot not loaded; run `mix-models fetch snapshot-1` |
| `InsecureKeyLengthWarning` | Harmless; suppress with `PYTHONWARNINGS=ignore` |

## Choosing a framework

| Aspect | OSeMOSYS | GCAM | MESSAGEix |
|--------|----------|------|-----------|
| **Runtime per scenario** | ~8 s | 15–30 min | 5–90 min |
| **Energy system detail** | 6 technologies | 50+ technologies | 20+ (GLOBIOM snapshot) |
| **Demand** | Exogenous YAML | Endogenous | Exogenous (calibrated) |
| **Policy lever** | CO2 caps + RES | Carbon price + RES | Carbon price + cap + growth |
| **Solver** | HiGHS (pip) | GCAM C++ | GAMS (license) |
| **Cross-sector** | Electricity only | Energy-water-land | Energy only |
| **Installation** | pip only | Compile from source + R | GAMS demo + pip |

OSeMOSYS: rapid iteration, transparent parameters. GCAM: cross-sector feedbacks.
MESSAGEix: IIASA-provenance scenario comparison, technology learning dynamics.
